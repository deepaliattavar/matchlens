# Submission checklist

The authoritative action guide is [START_HERE_SUBMISSION.md](../START_HERE_SUBMISSION.md).

- [ ] Final Windows install and 30 tests passed.
- [ ] Four checkpoints, personalization, export and review reset checked.
- [ ] Own original wording export backed up; provenance understood.
- [ ] Fictional names used for video unless permissions established.
- [ ] Public GitHub contains source, data, docs and setup instructions; no secrets or model files.
- [ ] CI checked, without claiming a pass before it runs.
- [ ] Functioning demo video under two minutes; public URL tested signed out.
- [ ] English description accurately identifies Foundry Local and its limitations.
- [ ] All required Innovation Studio fields complete.
- [ ] Working test build freely accessible through judging.
- [ ] Final submission action completed and confirmation saved before the official deadline.

Nothing in this package publishes or submits the entry automatically.
