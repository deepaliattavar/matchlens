# A short user-validation session

No user study has been completed. Use this protocol to collect actual evidence.

Ask a producer or sports-content editor to compare two recovery sequences, explain the outcomes and prepare a card. Use the same task first with the event table alone and then with MatchLens; if comparing multiple participants, alternate order to reduce learning effects. Use a fresh equivalent sequence for the second task if possible.

Record participant role (with permission), task version, time to a usable card, factual errors, requested edits, and whether the evidence was easy to inspect. Ask: “Would this fit your workflow? What would you need before using it?” Do not lead them toward positive feedback.

If the participant is not a broadcast professional, label results a usability check. A single session is qualitative feedback, not evidence of industry-wide time savings. Do not publish names or quotes without permission.
