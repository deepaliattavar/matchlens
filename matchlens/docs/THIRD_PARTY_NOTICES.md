# Dependencies and assets

This package includes original project code, authored synthetic data and a user-provided approved wording artifact. No real match footage, club logos, commercial music or model weights are bundled.

Direct dependency projects:
- Streamlit: https://github.com/streamlit/streamlit (Apache-2.0 project)
- pandas: https://github.com/pandas-dev/pandas (BSD-3-Clause project)
- Optional Microsoft Foundry Local SDK: https://github.com/microsoft/Foundry-Local (see SDK LICENSE.txt and applicable runtime/model terms)

Dependencies are installed with pip and retain their own license files and notices. Model licenses and native-runtime terms must be reviewed separately before any redistribution; the package does not redistribute them.
