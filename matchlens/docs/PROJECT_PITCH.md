# Project title
MatchLens

# Tagline
They won the ball. What happened next?

# Project description — ready to paste
MatchLens helps sports producers turn synthetic football recoveries into clear, evidence-backed stories. It follows each recovery until a shot is observed or possession changes, keeping unresolved outcomes open. Context highlights moments such as a first shot after several recoveries ended without one.

Python and pandas calculate the facts. Microsoft Foundry Local with Phi-4-mini supports local AI wording preparation, followed by human review. Reviewed templates are reused during replay without waiting for model generation. A Streamlit interface provides fan and analyst views, English and Spanish explanations, automated recovery recaps, and HTML/JSON exports with source evidence.

The prototype focuses on one production task: inspect a turnover, understand its outcome, choose an audience and export a reviewed story. All events are synthetic. AI drafting is optional and hardware-dependent; live analytics are deterministic. No paid API or Azure cloud deployment is required. The current exports are static demonstrations, with production renderer integration and measured producer impact left for future validation.
